# SILK Trinkgeld

Statische Web-App für Trinkgeldberechnungen. Der Zeitraum kann über Monatsgrenzen gewählt werden. Tagesbeträge lassen sich per SILK1-QR-Code, QR-Bild oder CSV übernehmen; bestehende Mitarbeiterdienste bleiben erhalten.

Die produktive Vercel-Domain ist https://silk-trinkgeld-uiux-polish.vercel.app.
